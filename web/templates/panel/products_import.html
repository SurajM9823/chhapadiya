Existing SKUs will be updated. New SKUs will be created.

How to Import / Update:

  • New products: Fill SKU, Name, MRP — all other fields optional.
  • Update existing: Use the same SKU — all fields will be overwritten.
  • Download the template below; it matches the export format exactly.
  • Grey columns in the export (Stock Qty, Image URLs, dates) are ignored on import.
  • Category, Sub-Category, Country, Delivery Time and Package must match names exactly.
